# Synthetic content-pipeline fixtures

Every name, shader, component type and hash in this directory is fictional. None of it is Monomi Park content or native evidence. `synthetic: true` is set everywhere, and products derived from these files are flagged synthetic.

The files are generated by `tests/conversion/world.py` (from `tests/`: `PYTHONPATH=.. python3.12 -m conversion.world --write`). `tests/conversion/test_e2e.py` fails if a committed file drifts from the generator.

- `source-sr1.json`, `source-sr2.json`: `bridge-content-source` v1 manifests (registry snapshot + metadata-only object graph).
- `material-profile-*.json`, `behaviour-profile-*.json`: synthetic source data profiles.
- `target-profile-*.json`: synthetic target profiles with fictional shader templates and fictional `synthetic.fixture.*` registration API names. Real targets use `builtin_target_profile()`, which names no API.

Scenario coverage:
- a shared species
- exclusives in both realms
- multi-material
- skinned with bone order
- optional VFX
- a missing optional texture
- a missing critical mesh
- an unknown behaviour
- an unknown material property
- an unknown shader
- a cycle
- a canonical collision
- a malformed entry
- a quarantined source
- plort, icon, pedia, localization and market relations
